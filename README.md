## 📖 About

Fan Control is a Windows utility developed by Rémi Mercier for managing the fans inside a desktop or laptop. It detects the fan and temperature sources exposed by the motherboard, GPU and storage devices, then lets you build custom curves, mix sensors, set trigger thresholds and hold or ramp speeds between fixed steps. Recent builds added plugin support for third party hardware, a configurable hysteresis window and improved detection for modern chipsets and hybrid GPU laptops.

If you came looking for a Fan Control download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes. The app runs as a small background service with a tray icon and a clean dashboard, so once your curves are saved you can leave it running and forget about it. It is aimed at people who want granular control over noise and thermals without flashing a custom BIOS or learning vendor specific software.

**Good for:** PC builders tuning case airflow · gamers reducing fan noise under load · quiet office builds · workstation owners with many fan headers · laptop users on hybrid graphics · tinkerers mapping sensors to curves · anyone replacing a noisy stock fan profile.

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| No fans detected after install | Run the app as administrator and rescan hardware in the settings tab. |
| Fan speeds jump up and down | Increase the hysteresis value and add a ramp up or ramp down time. |
| GPU fan not responding | Install the matching plugin for your card and restart the app. |
| Sensors show zero or stuck values | Update chipset and GPU drivers, then reboot and rescan. |
| Curves reset after reboot | Make sure the background service is set to start with Windows. |
| High CPU use on the dashboard | Reduce the polling rate in settings and close other monitoring tools. |
